# 翊華兒童程式｜創意冒險群島 v2.0

網站：**https://jackchung-taiwan.github.io/island/**

此專案是可直接使用的互動式課程探索網站，擁有 12 座浮空島、走動中的人物、可收合的左側介紹、島嶼建造工具、橋梁連接、課程說明、實作問答與集章護照。

## 操作方式

- **探索**：拖曳畫面旋轉島嶼、滾輪縮放、點擊島嶼觀看課程資訊。
- **收合左側區域**：使用介紹區的收合控制，騰出更多場景空間。
- **島嶼創意工坊**：開啟建造模式，選擇房子、樹木、花圃、路燈、長椅、氣球、旗幟等物件，在島上點擊放置。
- **橋梁**：選擇橋梁工具，依序選兩座島連接。
- **保存**：場景布置和任務進度會儲存在使用中的瀏覽器；清除瀏覽器資料可能重置進度。
- **闖關**：閱讀課程介紹，完成各島挑戰並收集徽章。

## 網站檔案與部署

網站部署於 GitHub Pages，`main` 分支根目錄。

**目前正式網站只需 `index.html` 一個檔案。** 該檔已內嵌完整的 CSS 與 JavaScript，可直接用瀏覽器開啟；儲存庫中原有的 `style.css` 和 `app.js` 為舊版保留檔案，**目前首頁不再載入**。

變更網站時，請編輯 `index.html`，部署來源為 Settings → Pages → Deploy from a branch → main / (root)。
